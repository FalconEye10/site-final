# Project Rules

## Versioning System (`v x.y.z`)

For every task where code, UI, or logic is modified, automatically update the version in `package.json` following the `v x.y.z` format:
- `x`: Major change (architectural overhaul, breaking changes, core framework changes).
- `y`: Minor change or big bug fix (new feature, major fix, significant enhancement).
- `z`: Shameful bug fix or super minor change (small UI fix, minor tweak, quick patch).
